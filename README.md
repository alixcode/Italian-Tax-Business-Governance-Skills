# Skill Principi Contabili Nazionali: repository Skills per la gestione contabile, fiscale e societaria delle imprese italiane

Repository di skills professionali, progettato per supportare dottori commercialisti, responsabili amministrativi e CFO nella gestione delle imprese italiane. Le skills sono strutturate per coprire l'intero ciclo di vita contabile, fiscale e societario, con riferimento costante alle normative vigenti.

Le fonti di riferimento sono aggiornate a:
- **OIC Binder 2024** (principi contabili nazionali, revisioni marzo 2024)
- **IAS Binder 2025** (principi internazionali omologati UE)
- **TUIR** — DPR 22 dicembre 1986, n. 917, aggiornamento 2026
- **IVA** — DPR 26 ottobre 1972, n. 633 (vigente fino al 31/12/2026) e **TU IVA** — D.Lgs. 19 gennaio 2026, n. 10 (efficace dal 1° gennaio 2027)
- **Codice Civile** — aggiornamento novembre 2024
- **IRAP** — D.Lgs. 15 dicembre 1997, n. 446
- **TU Sanzioni Tributarie** — D.Lgs. 5 novembre 2024, n. 173 (applicabile dal 1° gennaio 2026)
- **CCII** — D.Lgs. 12 gennaio 2019, n. 14, come modificato dai D.Lgs. 83/2022 e 136/2024

## Come usare le skills con Claude Code

Le skills di questo repository sono progettate per essere caricate in Claude Code come contesto di riferimento normativo e procedurale. Ogni skill è un file Markdown autonomo con frontmatter YAML che specifica area, fonti e data di aggiornamento.

**Utilizzo diretto:**

```bash
# Avviare Claude Code nella cartella del repository
claude

# Oppure caricare una skill specifica come contesto
claude --context skills/01-contabilita-generale/registrazioni-tipiche.md
```

**Utilizzo tramite CLAUDE.md:**

Aggiungere al file `CLAUDE.md` del progetto cliente un riferimento alle skills rilevanti:

```markdown
## Riferimenti normativi
Consulta le skills in /path/to/Italian-Tax-Business-Governance-Skills/skills/
per procedure contabili, fiscali e societarie standardizzate.
```

**Struttura di ogni skill:**

Ogni file di skill contiene:
1. **Frontmatter YAML** — `name`, `description`, `area`, `fonti` (elenco delle fonti normative), `aggiornamento` (AAAA-MM) e, ove pertinente, `conflitti_noti` (divergenze OIC/IAS/TUIR)
2. **Corpo della skill** — procedure, esempi, tavole di riferimento, formule, checklist operative
3. **Note interpretative** — chiarimenti su casi limite, circolari, prassi

Ogni cartella di area contiene un `README.md` con l'elenco delle skills, i casi d'uso e le fonti di riferimento dell'area.


## Come usare le skills su altre piattaforme

Le skill sono pensate per essere portabili e riutilizzabili anche su piattaforme diverse, mantenendo invariata la logica di fondo: fornire all’AI un metodo operativo strutturato, replicabile e controllabile. Una volta scaricata la cartella della skill dal repository, è possibile importarla direttamente nell’ambiente utilizzato. Ad esempio:
- su ChatGPT: Plugin > Skill > Carica skill; 
- su Mistral Vibe: Context > Skills > Carica skill; 
- su Perplexity: Computer > Skills > Carica skill. 
In questo modo la stessa base di istruzioni, controlli e procedure può essere utilizzata su più modelli e strumenti, lasciando al professionista la possibilità di scegliere la piattaforma più adatta al proprio flusso di lavoro.

## Gestione dei conflitti normativi OIC / IAS

Le skills distinguono sempre tra il regime contabile applicabile:

- **Bilanci in forma ordinaria (imprese non quotate):** si applica il Codice Civile (artt. 2423–2435-ter) e i **principi OIC**. In caso di lacuna OIC, si può fare riferimento agli IAS/IFRS in via analogica, ma solo se compatibili con la disciplina codicistica (OIC 11 § 10).
- **Bilanci consolidati di società quotate o che adottano volontariamente gli IAS:** si applicano i **principi IAS/IFRS** omologati dall'UE, ai sensi del D.Lgs. 28 febbraio 2005, n. 38.
- **Conflitti diretti:** quando OIC e IAS prevedono trattamenti contabili incompatibili (es. rivalutazione delle immobilizzazioni, capitalizzazione degli oneri finanziari), la skill indica esplicitamente quale regime si applica e in quale contesto (campo `conflitti_noti` del frontmatter).
